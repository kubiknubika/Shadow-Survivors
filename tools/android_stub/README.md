# Упрощённые объявления NDK

Эти заголовки **не** используются в сборке APK. Они нужны ровно для одного:
проверить, что `src/main_android.cpp` компилируется, когда под рукой нет NDK.

```bash
tools/check_android.sh          # g++ -fsyntax-only против этих объявлений
```

Настоящая сборка берёт настоящие `<android/*>`, `<EGL/*>`, `<GLES2/*>` и
`<aaudio/*>` из NDK — см. `design/android.md`. Если в NDK сигнатура отличается,
ошибку покажет уже сборка APK; здесь проверяются типы наших вызовов и то, что
игровое ядро (`game.h`, `renderer.h`, `audio.h`) собирается без Windows.
