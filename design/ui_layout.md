# Вёрстка: проверка «ничего не пересекается и не вылезает»

Релиз 2.12.16. Задача была сформулирована так: «проверь UI, чтобы нигде ничего
не пересекалось на разных разрешениях и форматах экрана во всех меню и режимах».

## Почему не глазами

Экранов двадцать три, достижимых кадров одиннадцать. Глазами проверяют то, куда
посмотрели, и обычно это 1280×720 в альбоме. Портрет, узкое 4:3 и сверхширокий
остаются непроверенными, а именно там текст и вылезает.

## Стенд `tools/ui_probe.cpp`

```
g++ -O2 -std=c++17 -pthread -Isrc tools/ui_probe.cpp -o build/ui_probe
./build/ui_probe              # сводка, код возврата 0 — чисто
./build/ui_probe --verbose    # каждая находка с координатами
./build/ui_probe 720x960      # один кадр
```

Как это работает:

1. Рендерер пишет в `Renderer::textLayouts` каждую нарисованную строку — тем же
   вызовом `drawText`, что и на экран. Стенд не может разойтись с игрой: текст,
   который игра не нарисовала, в проверку не попадёт. В игре журнал выключен
   (`textJournalEnabled = false`), включает его только стенд.
2. Чернильный прямоугольник считается по метрикам глифов (`bearingX/bearingY`,
   `width`, `height` из атласа), а не по `lineHeight`. Номинальная рамка
   объявляет вылетом строку, которая на самом деле влезает: у «У» и «Ц» хвост
   торчит ниже базовой линии, а у «ё» — выше.
3. Дефекты:
   * **вылет** — чернила выходят за кадр (срезанная буква, обрезанная строка);
   * **наложение** — чернила двух строк интерфейса пересекаются;
   * **обрезка** — строка шире своего окна прокрутки (печатается отдельно).
4. Что законно и дефектом не считается:
   * текст мира — подписи над существами, числа урона, всплывающий текст: тег
     слоя 1, `renderWorld` ставит его и возвращает прежний;
   * строка, не попавшая в своё окно прокрутки: её не видно, проверяется только
     то, что игрок реально видит;
   * числа без букв: иначе каждый показатель HUD давал бы пару со своей
     подписью.

## Достижимые кадры

Игра рисует в логические пиксели (`logicalScreenSize`, `src/renderer.h`):
в альбоме высота 720, в портрете ширина 720. Двадцать одно окно схлопывается в
одиннадцать кадров, и проверяются именно кадры, а не окна.

| кадр | из каких окон |
|---|---|
| 960×720 | 640×480, 1024×768, 768×576 |
| 1152×720 | 800×600, 1152×864 |
| 1200×720 | 800×480 |
| 1280×720 | 1280×720, 1366×768, 1440×900, 1600×900, 1680×1050, 1920×1080, 1920×1200, 2048×1152, 2560×1440 |
| 1728×720 | 3440×1440 (сверхширокий) |
| 720×960 | 768×1024 (планшет 4:3) |
| 720×1024 | 834×1194 (планшет) |
| 720×1152 | 800×1280 (планшет 16:10) |
| 720×1280 | 720×1280, 1080×1920 |
| 720×1568 | 1080×2340 |
| 720×1600 | 1080×2400 |

Окна 640×480, 800×480, 1024×600 и 1080×1920, на которых проверяли раньше, дают
кадры, которых в игре не бывает: «дефекты» на них были ложными.

## Что нашлось (и было починено в 2.12.16)

| место | дефект | правка |
|---|---|---|
| дары дня | карточки поверх панели заголовка (край шапки считался как топ-бар 68/46, а под ним панель 94 px) | `headerH = топ-бар + 4 + 94` |
| арена музыки | панель 250/48/780 при кадре 720 вылезала за край и накрывала «РЫВОК ГОТОВ» и резонаторы | ширина кадра, y=342 (портрет) / 200 (альбом) |
| справка | 8 строк = 1054 px уходили под кадр 960 и ложились на кнопки футера | число строк по высоте кадра |
| справка | третья подсказка 723 px срезалась правым краем | короткий вариант на узком кадре |
| справка | «Клятва Последнего Рассвета» × «АРТЕФАКТ • ТИР 5» (11 px) | название ужимается под подпись тира |
| справка | футер: «ВЕРНУТЬСЯ В МЕНЮ» × «СЛОВАРЬ [G]» (34 px при 720×1024) | кнопки делят строку |
| управление | «Левый большой палец ведёт стик…» (480 px) срезалась левым краем карточки 322–365 px | перенос по ширине карточки |
| финал кампании | строка итогов 738 px; третья кнопка за краем кадра 720 | две строки; в портрете кнопки столбиком |
| выход с добычей | «СОБРАНО ЗОЛОТА…» 749 px при кадре 720 | две строки |
| вид кнопок | подсказка (844) ложилась на «СБРОСИТЬ ВНЕШНИЙ ВИД» (842) | превью ограничено блоком строк |
| выбор героя | «между забегами.» × «ПОБЕДЫ НАД БОССАМИ» на карточке 280 px | счётчик идёт за переносом |
| HUD | баннеры прокачки/сундука/смерти на верхней полосе HUD | HUD не рисуется под полноэкранными окнами |
| портретный HUD | хвост второй подсказки срезался о нижний край | смещения −29/−16 |

## Результат

```
$ ./build/ui_probe
вылетов: 0, наложений: 0, обрезок: 0
ОК: ни одного вылета и ни одного наложения
```

Стенд проверен мутацией: если вернуть панель арены на `y=48`, он печатает
21 наложение и возвращает 1. То есть ловит именно то, что должен, а не молчит.

## Чего стенд не знает

* Плотность и вырез конкретного телефона: игра рисует в логические пиксели, а
  как их растягивает конкретное устройство — вне кадра.
* Цвет и контраст: стенд меряет геометрию, а не читаемость.
* Живые устройства: APK не собирался, на телефоне не проверялось.
