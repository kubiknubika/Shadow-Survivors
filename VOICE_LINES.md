# Фразы озвучки (реестр ↔ файлы)

Источник правды — `src/messages.h` (поле `voiceLine`). Здесь та же таблица в
удобном для записи виде: одна строка — один файл в `audio/voice/`.

Файл: `audio/voice/<ключ>.mp3`. Проверка комплекта: `python3 tools/check_voice.py`.

| Файл | Фраза | Когда звучит |
|------|-------|--------------|
| `boss_phase.mp3` | Новая фаза боя. | Смена фазы босса |
| `boss_warning.mp3` | Страж приближается. | Баннер «страж приближается» |
| `boss_summon.mp3` | Босс призывает помощь. | Босс вызывает свиту |
| `boss_ability.mp3` | Опасность. Уходи из зоны удара. | Телеграф способности босса |
| `breakthrough.mp3` | Особая орда. Прорыв! | Начало прорыва |
| `breakthrough_held.mp3` | Прорыв отбит. | Прорыв пережит |
| `breakthrough_held_banner.mp3` | Прорыв отбит. | Тот же клип для баннера |
| `breakthrough_pressure.mp3` | Орда не остановится, пока ты не получишь удар. | Давление орды |
| `breakthrough_warning.mp3` | Внимание, на следующем уровне прорыв. | Предупреждение |
| `hostile_horde.mp3` | Особая орда идёт на тебя. | Особая орда |
| `evolution.mp3` | Симбиоз пробуждён. | Эволюция оружия |
| `build_tier_up.mp3` | Тир сборки повышен. | Повышение тира |
| `mission_briefing.mp3` | Миссия начинается. | Вступление миссии |
| `mission_objective.mp3` | Цель обновлена. | Баннер цели |
| `endless_start.mp3` | Бесконечная ночь. | Старт бесконечного режима |
| `world_event.mp3` | Тихая охота. Стая вызвана. | Событие мира |
| `seal_lore.mp3` | Печать снята. | Лор после печати |
| `campaign_end.mp3` | Кампания завершена. | Финал кампании |
| `portal_found.mp3` | Найден эхо-портал. | Появился портал |
| `portal_used.mp3` | Портал закрыт. | Портал использован |
| `resonator_spawn.mp3` | Новый резонатор на поле. | Новый резонатор |
| `resonator_destroyed.mp3` | Резонатор разрушен. | Резонатор уничтожен |
| `trio_intro.mp3` | Три эха защищают сердце архива. | Финальное трио |
| `phoenix_revive.mp3` | Феникс возрождает тебя. | Возрождение феникса |
| `player_death.mp3` | Твоя искра погасла. | Гибель героя |
| `coin_hint.mp3` | Подбери монеты, которые оставила стая. | Подсказка про монеты |
| `voice_on.mp3` | Озвучка сообщений включена. | Подтверждение в настройках |

Намеренно без голоса (это попапы, а не сообщения): `exposed_weak_point`,
`supercrit`, `smart_kill`, `matryoshka`.
