# Именование аудио-файлов для ShadowSurvivors

Все треки в формате **MP3**. Класть в папку `audio/` рядом с `.exe`.

Игра декодирует эти файлы на ходу (встроенный декодер minimp3, `src/third_party/`),
поэтому конвертировать или переименовывать ничего не нужно: 48 кГц, стерео, 3–5 МБ —
всё играет как есть. Файл из `audio/` **заменяет** встроенную синтезированную тему
соответствующей сцены; если файла нет, для этой сцены остаётся встроенная тема,
то есть игра не замолкает даже с пустой папкой.

Громкость музыки, клавиша `[N]` и приглушение музыки во время громких эффектов
действуют и на файлы.

## Схема именования

`ss_<сцена>_<название>.mp3`

## Поддерживаемые сцены

| Сцена | Пример файла | Для чего |
|-------|-------------|----------|
| `menu` | `ss_menu_main.mp3` | Главное меню |
| `gameplay` | `ss_gameplay_run.mp3` | Основной бой: общий трек и плейлист |
| `case` | `ss_case_07.mp3` | Своя музыка делу 07 (главнее общего) |
| `boss` | `ss_boss_theme.mp3` | Битва с боссом: общий трек |
| `guardian` | `ss_boss_guardian03.mp3` | Своя музыка стражу 03 (главнее общего) |
| `victory` | `ss_victory_boss.mp3` | Победа над боссом |
| `gameover` | `ss_gameover_death.mp3` | Экран смерти |
| `forge` | `ss_forge_shop.mp3` | Кузница душ (магазин улучшений) |
| `upgrade` | `ss_upgrade_pick.mp3` | Короткий сигнал при выборе улучшения (UI) |
| `levelup` | `ss_levelup_ding.mp3` | Короткий сигнал при новом уровне |

## Несколько файлов на одну сцену

В сцену можно положить сколько угодно записей — все файлы вида
`ss_<сцена>_*.mp3` попадают в плейлист этой сцены.

| Режим | Как выбирается запись |
|-------|------------------------|
| Кампания | есть `ss_case_NN.mp3` — дело NN играет его всегда (вернулся в дело — та же музыка). Нет файла — общий плейлист `ss_gameplay_*` по номеру дела, чтобы соседние дела не совпадали. Нет и его — встроенная тема |
| Босс | есть `ss_boss_guardianNN.mp3` под тип стража (0…5) — играет он; иначе общий плейлист `ss_boss_theme*` |
| Бесконечный режим | весь боевой набор (`ss_gameplay_*`, `ss_case_NN`, `ss_gameplay_endless_*`) в перемешанном порядке: каждый трек играет один раз, потом набор тасуется заново, повтора подряд нет |
| Меню, кузница, смерть | случайная запись сцены, дальше зацикливается |

Так один и тот же набор файлов звучит по-разному в разных боях, и не нужно
переименовывать треки под каждое дело.

```
audio/
  ss_gameplay_run.mp3          # общий бой, если под дело файла нет
  ss_case_01.mp3               # дело 01
  ss_case_07.mp3               # дело 07
  ss_case_07_crypt.mp3         # вариант того же дела, чередуется
  ss_boss_theme.mp3            # босс без своего файла
  ss_boss_guardian05.mp3       # страж 05 (Двойник)
  ss_gameplay_endless_a.mp3    # эндлес-набор
```

Готовые промпты под каждое дело, стража, эндлес и служебные экраны — в
[`music_prompts.md`](music_prompts.md).

## Пример структуры

```
ShadowSurvivors_2.9.70.exe
audio/
  ss_menu_main.mp3
  ss_gameplay_run.mp3
  ss_boss_theme.mp3
  ss_victory_boss.mp3
  ss_gameover_death.mp3
  ss_forge_shop.mp3
  ss_upgrade_pick.mp3
  ss_levelup_ding.mp3
```

Если нужно несколько вариантов одной сцены:
```
ss_menu_main_a.mp3
ss_menu_main_b.mp3
ss_menu_main_c.mp3
```
Игра загрузит все подходящие файлы и будет выбирать случайный.

`ss_levelup_ding.mp3` и `ss_upgrade_pick.mp3` — это **одноразовые сигналы**, а не фон:
они проигрываются целиком поверх музыки (идут через шину эффектов, поэтому `[M]`
и ползунок эффектов на них влияют). Остальные шесть сцен — фоновые треки: играют
по кругу и сменяются с плавным переходом 120–300 мс при смене сцены.

Если файл не найден — игра не вылетает: для этой сцены играет встроенная тема.
Какие сцены реально закрыты файлами, видно в «Настройках» — строка `МУЗЫКА`
показывает количество и список найденных треков.

## Фразы голоса (озвучка сообщений)

Речь боя — это не системный синтезатор Windows, а **записанные файлы** в
`audio/voice/`. Имя файла равно ключу сообщения из реестра `src/messages.h`:

```
audio/voice/boss_phase.wav      ->  «Новая фаза боя.»
audio/voice/portal_found.wav    ->  «Найден эхо-портал.»
audio/voice/voice_on.mp3        ->  «Озвучка сообщений включена.»
```

Подходят и WAV (16 бит, PCM, моно/стерео, любая частота), и MP3 — сначала
ищется `<ключ>.wav`, потом `<ключ>.mp3`.

Правила:

- один файл = одна фраза, 1–3 секунды, WAV 16 бит или MP3, моно или стерео;
- имя строго `<ключ>.mp3`, ключи перечислены в `src/messages.h`
  (поле `key`) и в `VOICE_LINES.md`;
- нет файла — игра молчит по этой строке и честно пишет в `F3`
  «НЕТ ФАЙЛА n», так что забытую фразу видно сразу;
- фразы идут через шину эффектов по громкости: работают `[M]`, ползунок «Уровень
  эффектов» и переключатель «Озвучка сообщений»; но по приоритету это отдельная
  шина — под репликой эффекты и музыка приседают (см. ниже);
- проверить комплект: `python3 tools/check_voice.py` (или `--strict` в CI).

### Как реплика звучит в миксе

Реплика — не «ещё один эффект». В `src/audio.h` у неё своя шина
(`VOICE_BUS_GAIN = 1,45`), а эффекты и музыка приседают, пока она звучит: эффекты до
`0,58` (−4,7 дБ), музыка до `0,34`. Лимитер, который смягчает плотный бой, стоит
только на программной шине (музыка + эффекты); голос смешивается после него и
ограничивается отдельно на `0,94`.

Отсюда два практических правила:

- если реплика кажется тихой, сначала смотрите F3, строку `ГОЛОС ШИНА`: там усиление
  шины и текущий присед эффектов в дБ. Тихий клип и тихая шина — разные поломки, и
  лечатся они в разных файлах;
- подгонять громкость отдельного клипа «на слух в бою» не нужно: банк выровнен, а
  разницу даёт микс. Клип, выбившийся из коридора, ловит
  `python3 tools/check_voice.py --levels --voice`.

Текст, который записан в каждом файле, лежит в реестре (`voiceLine`) — если
фразу переписали, обновите и файл, и строку, тогда интерфейс и голос не разойдутся.
