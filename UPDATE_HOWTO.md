# Как обновить игру, если апдейтер пишет «обновлений не было»

## Что произошло

`update.bat` в корне игры — **старая копия**. Это видно по выводу: новый файл
печатает `[1/5] git fetch --all --prune` и строку `версия апдейтера: 2.10.23`,
старый — `[1/3] git fetch` и текст крякозябрами.

Старый файл ругается не просто так, у него две настоящие причины:

1. **Он сохранён в UTF-8.** `cmd.exe` читает `.bat` в кодовой странице консоли,
   поэтому русский текст превращается в `╨╛╨▒╨╜╨╛╨▓╨╗╨╡╨╜╨╕╨╡`.
2. **Ваша ветка удалена на GitHub.** `arena/0b44fe48-shadow-survivors` осталась
   только локально, поэтому `git pull` честно отвечает `Already up to date`, а
   версия в ней — 2.10.4.

## Почему «перекачал новый» не помогло

Кнопка **Raw** и обычная ссылка на файл отдают его из ветки по умолчанию, а это
`main`. В `main` до сих пор 2.10.4 и древний `update.bat` (2 КБ, UTF-8, LF).
Свежий апдейтер лежит **только в рабочей ветке**
`arena/dad71989-shadow-survivors`.

## Что сделать один раз

Открыть терминал в папке игры (**не** в подпапке) и выполнить:

```
git checkout -- update.bat
git fetch origin
git switch -c work --track origin/arena/dad71989-shadow-survivors
update.bat
```

Если Git ответит `a branch named 'work' already exists`, замените вторую строку на:

```
git switch work
```

### Что делают эти строки

| Команда | Зачем |
|---------|-------|
| `git checkout -- update.bat` | выбрасывает скачанный старый файл, иначе Git не даст переключить ветку |
| `git fetch origin` | забирает с GitHub то, что там есть сейчас |
| `git switch -c work --track origin/arena/dad71989-shadow-survivors` | переключает рабочую копию на ветку, где лежит свежая версия и свежий `update.bat` |
| `update.bat` | собирает игру из этой ветки |

Если есть свои несохранённые правки и Git отказывается переключаться, перед
`git switch` выполните `git stash -u`, а после — `git stash pop`. Ничего не
удаляется: правки лежат в stash.

## Дальше

Апдейтер сам находит ветку с самой свежей версией (`src/version.h`), поэтому
запускать его достаточно так:

```
update.bat
```

Он печатает, какую ветку и версию собирает:

```
[2/5] ветка arena/dad71989-shadow-survivors: версия 2.10.23, в main 2.10.4
```

Если этой строки нет — запустился старый файл, вернитесь к разделу «Что сделать
один раз».

## Как проверить, что запустился свежий файл

- вторая строка вывода: `версия апдейтера: 2.10.23`;
- шагов пять (`[1/5]` … `[5/5]`), а не три;
- в конце: `Готово. Версия 2.10.23, ветка …`.

Версия самого файла хранится в строке `set SELF_VER=`; при желании её видно так:

```
findstr SELF_VER update.bat
```
